# 技能分析

技能分析是 OPP 的独立指标，仅用于估计 osu! standard 玩家在八个维度上的能力分布，不修改 osu! 官方 PP、排名或成绩。

## 数据与覆盖率

- 首版读取当前登录玩家官方最佳成绩前 200，分两页请求。
- 优先从 Stable/Lazer 本地分析索引读取谱面；缺失时可在本次分析中从 OPP 在线谱面源获取，不写入凭据或用户配置。
- 结果会记录本地命中、在线回退、跳过数量及原因。在线源或谱面解析失败只影响对应成绩。
- 支持带 CL（Classic）标记的 osu! standard 成绩及其与已支持 Mod 的组合。CL 在当前技能模型中不额外改变谱面难度，成绩明细仍保留 CL 标记；HD、HR、DT 等 Mod 的难度修正照常生效。

## 算法来源

能力维度名称和公开行为参考 [Kert/osuSkills](https://github.com/Kert/osuSkills)。该仓库未声明可复用许可证，OPP 没有复制其 C++ 源码，而是依据公开模型在 Rust 中进行清洁重实现，算法标识为 `opp-osuskills-standard` v1。结果是 OPP 自有估计值，不承诺与 osuSkills 服务端数值完全一致。

成绩修正使用公开兼容行为：失误因子为 `0.97 ^ misses`，多数维度再乘以 `(combo / max_combo) ^ 0.8`；Accuracy 保留未按连击和失误修正的兼容行为。官方成绩权重优先使用响应中的百分比，缺失时按成绩顺序使用确定性的 `0.95 ^ index`。

## 联动
