# OPP 快速入门

> 仓库地址：https://github.com/osuplusplus/OPP
>
> 谱面相似算法研究仓库：https://github.com/osuplusplus/osu-difficulty-lab

## 1. 开始前准备

### 首次连接 osu! 账号

OPP 使用官方 osu! API v2，只申请 `public` 与 `identify` 权限。Client Secret 和登录 Token 会保存在系统安全凭据服务（Windows Credential Manager 或 Linux Secret Service），不会上传到 OPP 项目。

1. 打开 [osu! 账号设置](https://osu.ppy.sh/home/account/edit)，创建一个仅供自己使用的 OAuth 应用。
2. 将应用的回调地址填写为：

   ```text
   http://127.0.0.1:42831/oauth/callback
   ```

3. 启动 OPP，在初始设置页填写 Client ID 与 Client Secret。
4. 点击“使用 osu! 授权”，在系统浏览器中完成授权后返回 OPP。

## 2. 配置

Linux 用户请先阅读 [Linux 使用与构建](./Linux.md)，确保 `osu-wine` / `osu-lazer` 启动命令、Secret Service 和游戏数据目录已准备好。

1. 打开“设置”→“游戏目录”，分别为 osu! Stable 和 osu!lazer 选择安装目录或数据目录；也可以使用“自动检测”。目录可用后，OPP 会建立本地资源索引。
2. 如需使用相似谱面，请从 [`osu-difficulty-lab` Releases](https://github.com/osuplusplus/osu-difficulty-lab/releases) 下载最新的 Analyzer v3 索引数据集。
3. 如需使用 tosu 集成，请按需选择 tosu 与 tosu-lyrics 的程序路径，并配置 OBS WebSocket。

## 3. 功能总览

| 区域 | 可以做什么 |
| --- | --- |
| 在线谱面 | 按官网条件搜索、查看详情、试听、**批量下载**，以及跳转查找相似谱面。 |
| 谱面收藏夹 | 读取 Stable/lazer 收藏夹、导入或导出分享码；Stable 支持补齐缺失谱面并写回。 |
| 相似谱面 | **以指定谱面、最近成绩或 BP 为依据推荐本地索引中的相似谱面**；支持试听和快捷下载。 |
| 谱面练习生成器 | 从本地难度创建独立训练副本，调整速度与 AR/OD/CS/HP，按 BPM 或时间段截取。 |
| 数据中心 | 查看个人概览、排名轨迹、统计、BP 1–200、Pinned 成绩和详细档案。 |
| 本地谱面 | 扫描并筛选 Stable/lazer 谱面，查看难度参数、结构和详情，也可导出 `.osz`。 |
| Skin Workshop | 浏览 Skin 的配置、图片和音效；可组合 Stable Skin 的部件与配置，也可导出 `.osk`。 |
| 截图与回放 | 浏览、预览、复制路径或管理当前客户端的本地截图与回放。 |
| 回放渲染 | 将回放提交给 o!rdr 在线渲染；Windows 还可使用 Danser 在本机排队渲染并导出视频。 |
| tosu 直播集成 | 管理 tosu、OBS WebSocket、自动启动、浏览器源刷新和 OBS 实时歌词。 |
| 工具集合 | 谱面图预览、手速测试、Malody `.mcz` 转换和 lazer 空间工具；文件关联与显示器伽马仅限 Windows。 |
| 设置 | 主题、默认模式、试听音量、游戏目录、下载位置和镜像、缓存与高级选项。 |

**建议用户优先检查设置中的选项**

## 4. 核心功能怎么用

### 在线谱面：搜索、试听与下载

打开“在线谱面”后，可按标题、艺术家、Mapper、标签及官网筛选条件查找谱面。点击谱面卡片可查看谱面集和难度详情；在详情中可直接前往“相似谱面”。

- 使用卡片上的试听按钮预览音乐；试听音量可在“设置”中修改。
- 单张下载会在首次使用时询问保存目录。
- 勾选多个谱面后，在右侧下载面板批量下载；可查看整体进度、取消状态与失败信息。
- 默认下载源可在“设置”中选择小夜（Sayobot，默认推荐）、Hinai、Catboy 或 Nerinyan。下载失败时会自动尝试其他可用镜像。
- 开启“下载完成后自动打开谱面”后，系统会用默认客户端打开 `.osz`，由 osu! 自动导入。

### 相似谱面：先配置数据集

相似谱面功能在本机读取 Analyzer v3 数据集，不会上传索引内容。首次使用请：

1. 从 [`osu-difficulty-lab` Releases](https://github.com/osuplusplus/osu-difficulty-lab/releases) 下载兼容 Analyzer v3 的数据集。
2. 将数据集完整解压。
3. 打开“相似谱面”，点击“选择索引目录”，选择直接包含 `metadata.sqlite`、`features-v*.bin`、`indexes/` 和 `normalizers/` 的目录。

若解压后有两层同名文件夹，请选择内层的实际数据集目录。Analyzer v2 数据集与当前版本不兼容，需要重新下载或生成 v3 数据集。

配置成功后，支持三种起点：

- 输入 Beatmap ID，或从**本地谱面**详情一键带入。
- 使用最近成绩作为多个推荐种子。
- 使用 BP（最佳成绩）作为多个推荐种子。

默认由算法自动计算谱面参数权重；也可以在设置中开启高级模式，手动调整各难度维度权重。

常见用法是在“本地谱面”中展开谱面集，再对某个难度直接选择“查找相似”。

### 谱面收藏夹：同步、分享与补齐

“谱面收藏夹”可以读取 Stable 与 lazer 的收藏夹。你可以导入或导出 OPP 分享码，也可以检查收藏夹内缺失的谱面。

- Stable 支持下载缺失曲包、计算难度 MD5，并在确认后安全写回收藏夹。
- lazer 收藏夹当前只读，不会由 OPP 修改。
- 批量补齐期间可查看进度或取消任务；失败项目会保留原因，方便重试。

### 谱面练习生成器（Trainer）

在“本地谱面”展开任意难度，点击“导入 Trainer”。在生成器中可设置：

- 速度：`0.75–2.00×`；
- AR、OD、CS、HP；
- 最低/最高 BPM，只保留目标速度区间的物件；
- 起始/结束时间，只保留目标时间段。

点击“一键生成到 Songs”后，OPP 会在对应客户端的 `Songs` 目录创建独立副本，原谱面不会被修改。变速或截取音频时，首次使用需要系统已安装 `ffmpeg`。

### 本地资源：谱面、Skin Workshop、截图与回放

本地谱面和 Skin Workshop 都基于已配置的游戏目录扫描。Stable 使用目录索引，lazer 使用 `client.realm` 的只读快照和内容寻址存储；读取过程不会修改游戏数据库。

- 谱面页支持按标题、艺术家、Mapper、标签、在线 ID 与多种数值条件筛选，并可查看难度详情、跳转相似谱面或导出完整 `.osz`。
- Skin Workshop 可预览图片、播放音效并编辑 `skin.ini`。选择 Stable Skin 的部件、单个资源或配置项放入暂存区后，可应用到另一套 Skin，并在校验后覆盖或保存为新副本。
- 可直接打开 `.osk` 包参与编辑；临时打开的包必须保存为新 Skin。lazer Skin 当前只读，不支持融合或写入，但可在本地皮肤列表导出 `.osk`。

“截图与回放”提供当前客户端的媒体列表：

- 截图可在应用内预览，并可复制到系统剪贴板。
- 回放可读取基础信息，复制文件路径或在资源管理器中定位。
- 需要生成视频时，选择左侧的“回放渲染”。

### 回放渲染

回放渲染使用 o!rdr 远端服务。页面仅显示当前客户端中、对应**已提交 osu!standard 谱面**的本地回放；未提交谱面、其他模式，或没有输入数据的回放无法渲染。

选择回放后，设置分辨率、音量、署名和皮肤；“高级选项”可控制计分板、PP、光标、背景、Storyboard 等画面元素。提交后可以查看任务状态、打开或复制视频链接，并导出视频到本地。未使用验证 Key 的公开请求通常有每 5 分钟一次的限制；Key 只用于本次提交，不会保存。

Windows 用户如需完全在本机处理，可切换到 Danser 渲染。先在设置中选择 Danser、ffmpeg 和视频导出目录，再把支持的 osu!standard 回放加入队列。游戏会话结束后，OPP 也可以发现新回放并按你的偏好加入队列。Linux 当前仅支持 o!rdr 在线渲染。

### 数据中心

“数据中心”集中展示当前游戏模式的官方数据：

- 个人概览、排名轨迹、评价分布、长期活跃度与游玩生涯；
- BP 1–100 与 101–200；
- Pinned 成绩；
- 账号身份、社交资料、历史用户名、徽章、成就和详细档案。

切换游戏模式后，相关统计与在线谱面搜索会按所选模式刷新。

### tosu 与 OBS 直播集成

如需直播辅助，请先自行下载 [tosu](https://github.com/tosuapp/tosu/releases)。Windows 可另外配置 `tosu-proxy.exe` 实时歌词代理；Linux 请确保 `tosu` 位于 PATH，并安装 `pkexec`（PolicyKit）。

- 可启动或停止由 OPP 管理的 tosu，并查看当前谱面、分数、连击、PP、准确率和 Miss。
- 可设置检测到 osu! 或 OBS 后自动启动 tosu。
- 可连接 OBS WebSocket（默认 `ws://127.0.0.1:4455`），选择场景并刷新浏览器源；密码保存到系统安全凭据服务。
- 实时歌词会提供一个本地浏览器源地址，复制到 OBS 的“浏览器”源即可使用。

### 工具集合

- **谱面预览**：输入 Beatmap ID；osu!standard 可选择 strain 区间生成 GIF，Taiko、Catch 和 Mania 生成完整 PNG，结果可另存或在文件夹中定位。
- **手速测试**：按 5、10、15 或 30 秒统计 KPS，并换算近似 BPM。
- **文件默认打开端（仅 Windows）**：选择双击 `.osz` 谱面包和 `.osk` Skin 时使用 Stable 还是 lazer。
- **显示器伽马（仅 Windows）**：实时调整主显示器伽马；`1.00` 为默认值，可一键复原。显卡驱动重启后系统可能恢复默认值。
- **Malody 谱面转换**：选择一个或多个 `.mcz`，在源文件目录生成 `.osz`；同名输出会跳过，不覆盖原文件。
- **osu!lazer 占用统计**：按 lazer 配置定位数据目录，分别统计含硬链接的总大小、实际占用与文件数量。
- **Lazer Realm 读取测试**：以只读快照解析 `client.realm`，检查谱面集、原始文件名和内容哈希的读取结果。
- **压缩 Lazer 空间**：先预检 Stable `Songs` 与 lazer 中内容完全一致的文件，再确认是否将 lazer 副本替换为指向 Stable 文件的硬链接。执行前必须关闭 osu!，并确认两端目录配置正确；完成后建议启动 lazer 检查资源。

## 5. 设置说明

在“设置”中可完成以下常用配置：

- 切换深色/浅色主题和主题色；
- 选择默认 osu!、Taiko、Catch 或 Mania 模式；
- 调整在线与相似谱面的试听音量；
- 管理 Stable / lazer 目录及自动检测；
- 配置谱面下载位置、默认镜像和下载后自动导入；
- 开关相似谱面高级设置，并清除个人资料缓存；
- 查看当前连接账号与版本信息。

## 6. 常见问题

### 看不到本地谱面、Skin、截图或回放

请先到“设置”确认对应 Stable/lazer 游戏目录状态为“可用”，然后返回相关页面等待扫描完成。目录移动、删除或切换客户端后，需要重新选择或自动检测。

### 在线资料或成绩无法加载

检查网络连接与 OAuth 授权状态；如授权失效，重新打开应用并完成授权。不要通过共享 Token 的方式解决问题。

### 相似谱面提示索引不兼容

确认选择的是 Analyzer v3 数据集根目录，且目录包含所需文件。Analyzer v2 不能直接使用。

### Trainer 生成失败

先确认源谱面可在本地谱面页正常读取。若使用变速或时间截取，请安装并确保 `ffmpeg` 可用。

### 回放不能提交渲染

该回放必须属于已提交的 osu!standard 谱面，并且能够从本地索引匹配到对应谱面。请先重新扫描本地谱面，或更换符合条件的回放。

### tosu 或 OBS 显示未连接

确认程序正在运行、路径正确，且 OBS WebSocket 地址与密码一致。默认 OBS 地址为 `ws://127.0.0.1:4455`。Linux 还需确认 `tosu` 和 `pkexec` 可从 PATH 调用；首次启动会出现系统授权窗口。

### Linux 无法启动 osu!

OPP 使用 PATH 中的 `osu-wine` 启动 Stable、使用 `osu-lazer` 启动 lazer。请先在终端确认对应命令能够独立启动游戏，再重启 OPP；自定义数据位置需要在“设置”中手动选择。

## 7. 数据与隐私

OPP 仅使用你明确选择的本地目录和官方授权范围内的数据。OAuth 凭据、Token 与 OBS 密码使用系统安全凭据服务保存。相似谱面索引、游戏资源、截图和回放均在本机读取；使用回放渲染时，只有你主动提交的回放会发送给 o!rdr 服务。
