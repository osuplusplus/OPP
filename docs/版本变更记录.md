# OPP 版本变更记录

本文档按版本记录 OPP 的主要功能、界面和兼容性变化。

## 未发布

- 优化在线谱面、收藏夹、本地谱面及模式／Stable-lazer 切换：收藏夹按页挂载卡片，关闭的收藏弹窗不再读取全库；页面懒加载保留导航，模式更新可被后续操作打断。本地资源仅在索引变化时按客户端刷新，复用完整谱面集缓存，避免离开页面后批量重取后台数据；播放器进度更新不再重绘整个本地页。设置与身份读取、页面引导落盘、收藏状态探测移出主线程，读取设置和模式资料缓存时避免复制全部响应缓存。

- 重构主要重任务的线程调度：交互查询、批量计算和阻塞 I/O 分池执行，扫描与查重共享按 CPU 配置收敛的后台线程预算；本地查询、封面解码、PP 计算、压缩包导入及 FFmpeg 检测移出 UI／异步工作线程。增加任务队列上限与耗时日志，合并文件监听事件，为本地搜索增加去抖，并修复查重排队期间取消失效的问题。详见[线程与任务调度](./线程与任务调度.md)。

- 在线谱面下载校验镜像压缩包内的谱面集与难度 ID，发现过期难度时自动尝试其他下载源，并保留旧文件备份；相似谱面在线 .osu 文件改用 osu! 官方接口。

- 本地谱面页右上角新增音乐播放器，支持双库按谱面集合并、收藏夹和筛选结果播放、队列管理、四种播放方式、音量与进度控制；原试听共用后台播放核心，切换页面不再中断音乐。
- 新增 360×72 悬浮迷你播放器，可置顶、展开列表、恢复完整界面和收起到托盘。采用独立界面入口与后台流式解码，切换后释放主界面及闲置分析缓存；已有后台任务继续执行，完成后释放相关资源。支持系统媒体键与暂停状态恢复。
- 播放器改为半透明样式，展开列表时主栏保持高度并加入过渡动画；进度常态显示为底部细线，悬停后可拖动。迷你模式移除独立标题栏，以雾化谱面背景铺底并在悬停时显示窗口操作。空队列在启动时从本地谱库生成随机列表，建表过程减少逐文件磁盘校验，切歌优先开始播放再保存队列。
- 大屏本地谱面舞台会随播放器切歌定位当前谱面集和难度；跨 Stable／lazer 或游戏模式的曲目会同步切换相应谱库和模式，手动浏览不会被同一首歌的进度更新打断。
- 迷你窗口进一步收紧高度，置顶、恢复、托盘和关闭图标移至右上角悬停区域；切歌与播放控件保持可见且可点击。
- 修复迷你窗口拖动：按住封面、歌曲信息或空白处可移动窗口，按钮和进度条仍保留原有操作。

- 修复在线搜索框上移和舞台返回结果时的动画停顿；难度浮层滚到边缘后可继续滚动谱面列表，搜索提交后自动收起补全。新增底部快速导航、鼠标后退侧键、Alt+← 返回、/ 或 Ctrl+K 搜索、舞台 J/K 选曲与空格试听，并显示按键提示。

- 在线谱面采用“搜索首页 → 搜索结果 → 谱面舞台”流程：居中搜索与折叠筛选弹窗、独立缓存 15 分钟的近期热门（近 30 天上架、按累计收藏量取前 5 首）、搜索上移及舞台过渡动画，支持返回原结果与滚动位置。
- 难度详情改为覆盖后续卡片的独立浮层，保持卡片位置不变；结果数量与排序合并为紧凑工具栏，多选和批量加入收纳至更多菜单，排序及难度滚动条仅在交互时显现。

- 在线谱面信息区新增状态徽标、当前难度 BID 官网跳转、上架/上传日期及同名搜索；操作栏保留试听、下载、收藏，其余功能收纳至更多菜单。
- 统一在线谱面热门、结果网格与舞台侧栏卡片，扩大信息层级和间距并加入独立试听。搜索框支持清空，浏览状态使用“在线谱面”标题，排序改为可切换方向的按钮。

- 在线谱面结果与舞台背景改为渐变衔接，结果项常驻显示难度图标，悬停或键盘聚焦可查看各难度参数；新增从当前已加载筛选结果中随机选谱。
- 在线谱面舞台会随选曲立即读取并持久缓存小夜原始背景，失败时回退官方封面；标题、艺术家随背景取色，参数增加易区分的柔和配色，并修正结果封面比例及难度浮层色彩。设置页同时标注在线背景与小夜镜像下载的服务来源并链接小夜官网。
- 下载面板改为隐藏清单，支持跨搜索与页面切换累积、按筛选收集前 50／100／250／500 首、批次固定和后台进度；成功或跳过项自动移除，失败及取消后的未完成项保留。

- 主导航选中态改为柔和圆角底色，移除侧边线和底部细线；统一本地谱面底部工具栏与按钮的圆角层次。

- 本地万能搜索支持曲名、曲师、谱师、难度、来源、标签和 ID 跨字段组合匹配；候选菜单加入弹出动画，精简提示并优化随封面配色的滚动条。

- 合并品牌区与窗口标题栏，移除第二行全局工具栏，扩大页面与侧栏可用空间；游戏模式、Stable／Lazer 切换和首次扫描入口移至“设置 → 常规”。
- 左下角启动区整合游戏检测状态、当前客户端与模式，支持一键启动默认客户端、展开启动其他客户端，以及启动失败提示。

- 本地选谱进一步精简：难度与参数直接叠加在封面上，底部保留单排操作，播放按钮改为图标，并提高遮罩和操作栏透明度。

- 本地谱面页改为单个谱面集的背景主舞台与底部操作台，支持背景取色、明暗主题和减少动态效果；常用功能与完整难度列表直接可见。
- 本地选谱增加键盘搜索菜单、完整谱面集查询、按筛选随机选谱和高清背景，保留已有搜索条件与谱库管理能力。
- 增加 Stable／Lazer 本地音频手动试听，支持谱面试听起点、暂停和进度控制，切换谱面或离开页面自动停止。

- 修复技能分析将带 CL（Classic）标记的 osu! standard 成绩判定为不支持并跳过的问题，同时使旧分析缓存失效。
- 本地 Stable/Lazer 数据目录加入后台文件监听。谱面或 Skin 发生新增、修改、删除后，OPP 会在短暂去抖后自动执行增量索引，只重新解析变化项并保留未变化项的缓存结果。
- 本地资源页显示监听状态，以及上次增量更新的新增、修改、删除和复用数量；仍可使用“强制重建”解决外部程序批量写入导致的异常情况。
- 新增“技能分析”：基于官方最佳 200 成绩计算 osu!standard 八项能力，优先使用本地谱面并支持在线临时回退，可联动相似谱面与 Trainer。

## v0.4.3



- 新增 Skin Workshop：可打开 Stable Skin 或 `.osk` 包，暂存并融合部件、资源和 `skin.ini` 配置；支持覆盖前校验或另存为新 Skin。
- 本地资源接入 lazer Realm 只读索引，可读取谱面与 Skin 元数据，并将 Stable/lazer 谱面集、Skin 导出为 `.osz` / `.osk`。
- 新增谱面图预览：输入 Beatmap ID 后，osu!standard 可按 strain 区间生成 GIF，其他模式可生成完整 PNG 并另存到本地。
- 新增“压缩 Lazer 空间”：预检 Stable 与 lazer 中内容完全一致的文件，并可将 lazer 副本替换为硬链接；支持进度、取消和释放空间统计。
- 在线谱面新增小夜（Sayobot）镜像源并完善多镜像回退，修复筛选、下载与谱面详情中的兼容性问题。
- 更新 pp 计算依赖至 `Apeuriox/rosu-pp@pp-rework-202607`，同步最新 pp rework 算法快照。
- 改善 Linux 下客户端启动、文件定位、音频解码和 Wayland 渲染提示，并修复 Danser、tosu、游戏会话及本地资源扫描中的多项问题。

- 新增 osu!lazer 磁盘占用统计，区分包含硬链接的总大小与实际占用。
- 增加跨平台进程、路径和凭据适配，改善 Linux 环境及 tosu/OBS 联动兼容性。
- 补充 Linux 环境依赖、客户端命令、XDG 数据目录、构建流程和平台能力说明。
- 修复在线谱面筛选、Trainer、游戏会话统计和本地渲染中的多项问题。

- 用户可见功能、界面布局、协议和兼容性变化都应在本文件新增版本条目。
