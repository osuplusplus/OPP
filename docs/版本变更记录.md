# OPP 版本变更记录

本文档按版本记录 OPP 的主要功能、界面和兼容性变化，**只描述最终变化与用户可感知的结果**；问题的排查过程、根因分析与修复策略记录在[问题排查实录](./问题排查实录.md)。

## v0.6.1

本版聚焦三件事：**PackHub 接入 RomAI 比赛图池与 osu!Collector 社区收藏**、**游戏内覆盖重做交互（多人聊天翻译、自动补缺）**，以及**下载与收藏夹导入链路的稳定性**。

### PackHub：比赛图池与社区收藏

- PackHub 来源切换改为常驻分段控件（社区曲包 / osu!Collector / 比赛图池），当前来源以主题色高亮；同一搜索词在三个来源间通用（保留 BPH 分享码识别）。默认来源为 osu!Collector 收藏集合，打开页面即浏览。
- 新增“比赛图池”来源：浏览 romai.dev 公开图池库（全量 1336 个比赛图池）。图池卡片为四联封面拼贴 + ELO 段位徽章 + 各模组数量色签（NM/HD/HR/DT/FM/TB，配色对齐 RomAI 官网）；按段位（Candidate→Quantum，门槛与 RomAI 一致并经全量数据计数校验）筛选、ELO/名称排序，全部在客户端完成。全量索引缓存在应用数据目录（1 小时内复用、支持 ETag 条件请求与断网回退）。
- 图池详情弹窗按模组分组展示全部图位，每张图带 `NM1/HD2/DT3/TB` 槽位标识，谱面资料经 osu! 官方接口 + 镜像双通道补全；一键“同步为收藏夹”后即可在收藏夹页按图位练习、补齐缺失谱面。
- osu!Collector 来源提供与官网一致的排序（相关度、收藏数、最新上传、各模式谱面数量）与命中总数；收藏卡片改为数据卡——1-10★ 难度分布直方图（色阶对齐官网）、各模式难度数量、收藏数、上传者头像与更新时间。
- osu!Collector 收藏可一键导入为本地收藏夹（名称带 `[OC]` 前缀），可选“同时下载缺失谱面”走镜像级联补齐；导入按页节流拉取全部难度（含 MD5 校验和），进度实时回传。该站点在部分地区需要国际网络，无法连接时给出明确提示。

### 游戏内覆盖（实验性）

- 独立透明置顶小窗，不注入游戏进程：HUD 卡片默认点击穿透，显示菜单状态、当前谱面与下载进度；全局热键（默认 `Control+Shift+O`，可录制配置）唤出 Direct 面板，在游戏内搜索谱面、查看本地已有标记并一键下载导入，补上 stable 缺少的 osu!direct 体验。游戏启动可自动拉起 tosu。
- 覆盖改为 Steam 式交互：平时完全隐藏、不遮挡游戏画面，按热键唤出、再按或 `Esc` 收起；“游戏运行时常驻 HUD 状态卡”为可选项（默认关闭）。
- Direct 面板重构为 osu!官网/lazer 同款谱面卡片 UI：封面 + 渐变标题、上架/Loved/过审/待定/坟场状态徽标、按星数渐变着色的难度条，本地已有/部分/缺失标记与一键下载保留。
- 多人房间聊天与翻译：Direct 面板“聊天”标签页经 osu! IRC 实时显示 `#mp_` 频道全体玩家消息，外文消息自动翻译并以 `↳` 附译文；HUD 收起时显示未读徽标。翻译服务四档可选（Google 免费端点 / 腾讯云 / 百度 / OpenAI 兼容 LLM，凭据仅存系统密钥环）。
- 多人房间自动补缺改用 osu! IRC 通路：监听 BanchoBot 换图播报，本地没有的谱面也能实时检测并自动下载导入；补缺编排在后端常驻。
- 全屏覆盖方案：把 OPP HUD 装入 tosu 内置的游戏内渲染（D3D/OpenGL 钩子直接绘制进游戏画面），独占全屏下也可见；一键安装并合并 `__ingame__` profile，保留用户已有覆盖配置。
- 聊天连接可诊断：连接状态横幅分状态给出指引，认证失败不再无限重连；tosu 连接断开自动指数退避重连。
- 已知限制：置顶小窗在独占全屏下不可见（请启用游戏内渲染或以无边框运行）；Direct 搜索需要已登录；osu! IRC 为官方明文认证；Linux 需要 X11，待实测。

### 下载与收藏夹

- 新增 osu.direct 与 Nekoha Mirror 两个下载镜像；全部下载级联更新为：小夜（主力）→ osu.direct → Nekoha → Catboy → Nerinyan（Nerinyan API 自 2026-11 起长期不可用，降为末位兜底）。镜像健康探测覆盖全部六个镜像。
- lazer 收藏夹改为本地直读 `client.realm`，不再依赖外部 CollectionManager 程序；Realm 为只读格式，lazer 收藏夹为只读镜像，收藏管理与写回仍面向 Stable。
- 工具集合新增“谱面列表云备份”：把本地谱面库的谱面集 ID 列表上传到 OPP 社区服务器（每账号一份、上限 20000），可随时读取比对、一键“恢复为收藏夹”并批量补齐下载。
- 收藏夹缺失谱面补齐支持大批量：下载与安装按 500 个一批顺序执行；补齐安装新增谱面集级回填，无难度 ID 的占位条目下载后也能回填精确 MD5 与元数据；数万条目的恢复与批量插入不再卡顿。

### 问题修复

> 具体排查过程与根因分析见[问题排查实录](./问题排查实录.md)。

- 批量下载失败项自动重试两轮（轮间冷却 5 秒），修复“一键导入收藏夹第一轮下不全、手动重跑才补齐”；重试进度有明确提示，只有最终失败计入结果。
- 导入 Stable 完成提示补充 F5 刷新指引：运行中的 osu! 不会自动发现新解压的曲包目录，需进入歌曲列表按几次 F5（游戏未运行时启动即自动扫描）。
- 修复“导入 Stable 后游戏内始终没有收藏夹”：osu! 遇到重名收藏夹会丢弃该项及其后全部条目。现在写回时同名收藏夹自动合并，创建/重命名时校验重名，`COLLECTION_CONFLICT`（osu! 退出重写导致指纹过期）自动“读取 Stable 合并后重试”，不再需要手动刷新。
- 修复 osu! 退出覆写收藏夹导致 OPP 写入丢失：全局监视器在游戏退出后先合并游戏侧变更再自动补写，启动时若 stable 未运行也会收尾自愈；写回失败以任务失败形式提示。
- 「导入 Stable / 补齐谱面」真正一键化：osu! 运行中不再整体报错，下载与解压照常完成，collection.db 写回自动延期到游戏退出后。
- 修复在线谱面页大量“本地状态未知”：单个损坏谱面文件的扫描诊断不再使整个索引被判不可信；扫描中断、扫描中、来源离线或变更时仍保守显示未知。
- 修复 osu! 服务瞬时故障（超时/5xx/429）把用户强制登出：现在仅刷新令牌被明确拒绝时才要求重新登录，瞬时错误保留凭据自动重试。
- 修复 2014 年前老谱面在所有镜像上误报“下载失败”：无 ID 难度按归一化标题兜底校验，仍能拦截真正的串包；收藏条目回填增加标题两级回退。
- “一键导入 Stable”与游戏内 Direct 面板的谱面导入统一改为直接解压进 Songs：不再受系统 .osz 关联影响，也不会在 osu! 冷启动期间整批丢失导入参数；lazer 分支保留参数启动，“交给系统打开”保留为高级选项。
- 收藏夹补齐不再把 .osz 文件参数塞给 osu! 启动进程（冷启动期间会整批丢失、偶发系统弹窗与游戏卡死）；部分下载失败不再把整个任务标为失败，完成态注明失败数并可逐项重试。
- 修复多谱面并行下载时各展示位曲名来回闪跳：统一经“固定当前条目”的进度适配器。
- 修复“导入收藏夹到 Stable”打开错客户端：优先用已配置的 stable 可执行文件导入，仅探测失败时回退系统关联。
- 修复更新公告从未显示：检查更新时从 GitHub Releases API 读取发布说明，获取失败静默降级。
- 修复 osu!Collector 空关键词浏览报 500：与官网前端一致始终携带 `search` 参数。
- 修复 OTD 进程状态检测（`tasklist` 表格截断长进程名，改用 CSV）与 OTD 配置摘要（优先 `settings.json`/`config.json`）；OTD 建议选择守护进程 `OpenTabletDriver.Daemon.exe`。
- 修复 OTD / tosu / 歌词代理路径选择后被旧设置快照覆盖回空：路径写入后立即同步前端缓存，设置查询不再永久缓存。
- 修复 lazer 索引重启后报 `invalid type: null, expected f64`（BPM 非有限值落库）：入库前收敛，历史损坏条目恢复时自动跳过并自愈。
- 修复 Linux AppImage 下动态链接器变量泄漏：SteamOS 等桌面用 `xdg-open` 打开 OAuth 授权页崩溃的问题（issue #51）；应用内打开外部链接统一增加 scheme 校验。
- 本地媒体页面的文件大小显示统一为 KB／MB／GB／TB 格式。

### 界面与性能

- 技能分析页面重设计：分阶段加载面板（八边形雷达占位 + 已耗时计数），结果页改为雷达主视觉布局——放大的八维雷达图、可点击筛选明细的能力排行条、真正最弱四维的短板练习条带，成绩明细增加序号、连击数与维度贡献列。
- 引入 React Compiler：构建期自动为全部组件/钩子插入记忆化，游戏运行时高频事件、列表滚动、实时预览时间轴等场景的重渲染大幅收敛；本地已有标记不再周期性全量重查。
- 便携版更新安全加固：更新清单新增便携 EXE 的 SHA256，下载落盘前强制校验，缺失或不匹配拒绝自动更新；更新包地址锁定为官方 GitHub Release 前缀。
- 死代码清理与依赖瘦身。

## v0.6.0

- 新增个人资料生涯快照与活动时间线：按当前模式每日保存资料统计、Top 200 成绩、奖章和本地媒体变化；数据中心提供日／月／年热力图、可切换趋势指标和日期详情，并区分真实快照、缺失、失败、未知、部分采集与跨日累计，避免同一成绩变化重复通知。
- 新增社区大厅：提供比赛公告和约玩大厅，支持瀑布流浏览、搜索筛选、分页、详情查看、作者管理、到期归档及 osu! 联系入口；比赛公告支持主办方信息、筹备状态、日期待公布和 STAFF 招募内容。
- BeatmapHub 改为使用 VPS 公开数据，移除客户端曲包缓存和旧数据回退；访客可直接浏览，身份设备管理、发布、更新和补齐流程保持草稿并支持重试。
- 工具集合新增“视频闪退修复”：扫描 osu!stable 谱面目录中的视频，优先无损重封装为 FLV，编码不兼容时按原码率转码，校验输出后通过同目录原子替换写回。
- 修复 Linux AppImage 在 Wayland 下的灰屏问题，以及内置 `xdg-open` 遮蔽系统打开器导致 OAuth 无法打开浏览器的问题；修复 lazer 本地索引恢复时序，减少重启后误报需要重新扫描。

## v0.5.0

### 本地数据库与已有谱面标记

- 新增独立 SQLite 索引库的创建、结构版本迁移及身份校验；首次启动可使用推荐目录、选择保存文件夹或暂时跳过。
- 设置中的“本地数据”页面增加数据库位置与状态，支持路径失效后的重试及原数据库重新定位；正常数据库暂不支持搬迁。
- 自动将兼容的本地谱面、皮肤和资源索引迁移到数据库，优先读取数据库；扫描后按条目事务增量更新，数据库不可用时回退 JSON，并防止重启误读旧索引。
- 在线热门、搜索结果和具体难度显示本地已有／部分已有／未知状态。已有标记采用与 Ranked 一致的图标徽标样式。设置新增“本地数据”分类，集中管理数据库、每个客户端的索引数量与持久化状态、索引同步和增量扫描，以及标记开关和 Stable／lazer 匹配范围。
- 匹配基于最近扫描的谱面 ID，文件版本可能不同。游戏大文件和相似数据集不迁移，也不采集生涯数据。后续生涯记录将使用独立数据库，设计见[本地数据库](./本地数据库.md)。

### 回放渲染工作台

- 实时预览、Danser 和 o!rdr 统一为沉浸式工作台：共享右上角向下展开的素材库与任务输出面板，保留素材搜索；移除底部任务区及预览区域标题，统一三个入口的主区域尺寸，支持浅深主题及窄窗口。
- 可从任意目录多选 `.osr`；手选素材在本次运行期间跨页面保留，不复制原文件。损坏、超限、缺失文件与谱面不兼容状态分别提示，支持重新匹配。
- Danser 支持勾选回放批量入队，整批校验后保存参数快照；修复外部回放导致谱面／皮肤目录解析错误的问题。
- 切换模式或离开页面时关闭原生预览；后台导出进度继续接收，返回工作台可查看完成结果。

### 收藏夹、图池与 BeatmapHub

- BeatmapHub 推荐、搜索和曲包详情直接读取 VPS；移除本地曲包缓存、离线旧数据回退和按 manifest hash 隐藏曲包的逻辑，重新进入页面时请求最新数据。

- 收藏页改为文件夹网格与分页谱面列表，支持全收藏跨字段搜索、图位排序、全夹星数／BPM 摘要、记录进度，以及进入本地准确难度后恢复浏览位置。
- 新增按收藏夹保存的彩色标签、自动保存笔记、手动成绩历史与代表成绩；只读查询 Stable／lazer 本地成绩，区分玩家、谱面内容版本和计分体系。个人记录不写入游戏数据库或分享码，图池同步保留记录。
- 发布 [OPP URI 标准 v1](./OPP-URI标准.md)：从公开 HTTPS JSON 导入 osu!standard 图池，兼容 ASC 星域杯旧链接。首次导入展示任务阶段，重复打开优先读取本地快照，更新由手动同步触发。
- URI 图池默认仅保存在 OPP；下载曲包、导入 Stable 和逐图在 lazer 中打开分别操作。图池持久保存在线谱面参数，未下载也可浏览；旧快照补全资料不改变成员或 Stable 同步范围。
- 收藏夹详情收起总览工具栏及图池设置，下载完成结果可折叠；图位使用彩色徽标，保留选图人、评论、定制／原创标记和练习记录。浏览与存储说明见[收藏夹浏览与个人记录](./收藏夹浏览与个人记录.md)。
- BeatmapHub 改为社区发现首页，统一搜索与分享码入口，显示已有／缺失数量，支持访客预览和导入。发布、更新与身份设备管理使用独立弹窗，保留连接身份前的草稿；补齐失败可复用原收藏重试，修复删除入口和复制失败反馈。

### 在线谱面与下载

- 在线浏览采用“搜索首页 → 结果 → 谱面舞台”流程，返回时恢复筛选与滚动位置；近期热门展示近 7 天上架、按累计收藏量排序的前 5 首，缓存 15 分钟。
- TREND 热门卡片改为紧凑横向列表，难度详情在卡片下方展开；统一本地谱面难度条的滚动条样式，移除 tosu 页顶栏的 API 连接徽标。
- 统一首页搜索、结果卡片与舞台信息层级，提供高清背景取色、独立试听、难度悬停详情和当前已加载结果随机选谱；补充快捷键、鼠标后退与搜索导航。
- 下载清单改为全高抽屉，支持跨页面累积、按筛选批量收集、固定批次和后台进度；成功／跳过项自动移除，失败及取消后的未完成项保留。
- 在线／图池下载最多两路并行，增加响应、停滞和低速超时；默认优先小夜，再回退 Catboy、Nerinyan，Hinai 仅手动启用。校验曲包谱面集与指定难度，允许同曲包附带 BID 为 0／-1 的未提交难度，替换旧文件前保留备份。
- 下载结果支持一键打开已下载曲包、失败重试和官网补下载入口；官网补下载由已登录浏览器处理，曲包打开使用系统文件关联。修复文件名中的 URL 编码，并合并下载完成通知。

### 相似谱面与技能分析

- 重构 Standard／Mania 工作区：本地搜索先选谱面集再选难度，支持 BID／链接、最近游玩和 BP 推荐；统一筛选确认、高清候选舞台、维度图、逐首历史、试听、下载、预览与收藏。
- 新增可记忆的“过滤今日已推荐”开关；最近游玩与 BP 推荐在截取参考数量前按 NM／DT／HT 或混池筛选，快速推荐和完整推荐使用相同 Mod 池。
- Mania 接入 `osu-difficulty-lab@92b791c` 的 v4 运行包，直接读取预计算的 NM／DT／HT 特征和键型，无需附带 `.osu` 源文件。支持六维 MMA 覆盖率、主模式、细分键型及 RC／LN 比例；缺失记录明确提示，无在线 ID 的本地记录禁用在线操作。兼容要求见[相似谱面数据集](./similarity-dataset.md)。
