# OPP 版本变更记录

本文档按版本记录 OPP 的主要功能、界面和兼容性变化。

## v0.5.0

### 收藏夹、图池与 BeatmapHub

- 收藏页改为文件夹网格与分页谱面列表，支持全收藏跨字段搜索、图位排序、全夹星数／BPM 摘要、记录进度，以及进入本地准确难度后恢复浏览位置。
- 新增按收藏夹保存的彩色标签、自动保存笔记、手动成绩历史与代表成绩；只读查询 Stable／lazer 本地成绩，区分玩家、谱面内容版本和计分体系。个人记录不写入游戏数据库或分享码，图池同步保留记录。
- 发布 [OPP URI 标准 v1](./OPP-URI标准.md)：从公开 HTTPS JSON 导入 osu!standard 图池，兼容 ASC 星域杯旧链接。首次导入展示任务阶段，重复打开优先读取本地快照，更新由手动同步触发。
- URI 图池默认仅保存在 OPP；下载曲包、导入 Stable 和逐图在 lazer 中打开分别操作。图池持久保存在线谱面参数，未下载也可浏览；旧快照补全资料不改变成员或 Stable 同步范围。
- 收藏夹详情收起总览工具栏及图池设置，下载完成结果可折叠；图位使用彩色徽标，保留选图人、评论、定制／原创标记和练习记录。浏览与存储说明见[收藏夹浏览与个人记录](./收藏夹浏览与个人记录.md)。
- BeatmapHub 改为社区发现首页，统一搜索与分享码入口，显示已有／缺失数量，支持访客预览和导入。发布、更新与身份设备管理使用独立弹窗，保留连接身份前的草稿；补齐失败可复用原收藏重试，修复删除入口和复制失败反馈。

### 在线谱面与下载

- 在线浏览采用“搜索首页 → 结果 → 谱面舞台”流程，返回时恢复筛选与滚动位置；近期热门展示近 7 天上架、按累计收藏量排序的前 5 首，缓存 15 分钟。
- 统一首页搜索、结果卡片与舞台信息层级，提供高清背景取色、独立试听、难度悬停详情和当前已加载结果随机选谱；补充快捷键、鼠标后退与搜索导航。
- 下载清单改为全高抽屉，支持跨页面累积、按筛选批量收集、固定批次和后台进度；成功／跳过项自动移除，失败及取消后的未完成项保留。
- 在线／图池下载最多两路并行，增加响应、停滞和低速超时；默认优先小夜，再回退 Catboy、Nerinyan，Hinai 仅手动启用。校验曲包谱面集与指定难度，允许同曲包附带 BID 为 0／-1 的未提交难度，替换旧文件前保留备份。
- 下载结果支持一键打开已下载曲包、失败重试和官网补下载入口；官网补下载由已登录浏览器处理，曲包打开使用系统文件关联。修复文件名中的 URL 编码，并合并下载完成通知。

### 相似谱面与技能分析

- 重构 Standard／Mania 工作区：本地搜索先选谱面集再选难度，支持 BID／链接、最近游玩和 BP 推荐；统一筛选确认、高清候选舞台、维度图、逐首历史、试听、下载、预览与收藏。
- 新增可记忆的“过滤今日已推荐”开关；最近游玩与 BP 推荐在截取参考数量前按 NM／DT／HT 或混池筛选，快速推荐和完整推荐使用相同 Mod 池。
- Mania 接入 `osu-difficulty-lab@92b791c` 的 v4 运行包，直接读取预计算的 NM／DT／HT 特征和键型，无需附带 `.osu` 源文件。支持六维 MMA 覆盖率、主模式、细分键型及 RC／LN 比例；缺失记录明确提示，无在线 ID 的本地记录禁用在线操作。兼容要求见[相似谱面数据集](./similarity-dataset.md)。
- 新增基于最佳 200 成绩的 osu!standard 八项技能分析，优先读取本地谱面，可在线补齐并联动相似谱面和 Trainer。修复 CL 成绩被跳过的问题；按谱面与 Mod 增量复用能力向量，缓存按客户端和在线补齐策略隔离，保留一小时并展示复用数量。
- 移除设置中失效的相似谱面选项，Standard 权重与结果数量集中到工作区；不支持的模式引导至“设置 → 常规 → 游戏模式”。

### 本地资源、播放器与回放

- 本地谱面改为背景舞台与底部操作台，支持跨字段万能搜索、准确难度选择、高清背景及随机选谱。Stable／lazer 后台文件监听触发增量索引，显示新增、修改、删除与复用数量，并保留强制重建入口。
- 新增本地谱库音乐播放器，支持双库合并、收藏／筛选结果播放、队列、四种播放方式、音量与进度控制；试听共用后台播放核心，切换页面不中断音乐，本地舞台可随切歌定位客户端、模式与难度。
- 新增 360×72 悬浮迷你播放器，支持置顶、拖动、列表、系统媒体键、托盘与主界面恢复；流式解码并释放闲置界面和分析缓存，后台任务继续执行。
- 修复 lazer Realm 并发快照、`current` 安装目录版本识别、手动数据路径占用统计和同名皮肤预览冲突；明确 lazer 收藏读取错误及 Stable 写回目标，Trainer 遵循 Stable 自定义谱面目录。
- PP 计算与相似谱面在线源文件优先使用官方 `.osu` 接口；修复回放导出在皮肤准备失败后无法重新提交，以及 Linux/X11 小数缩放下原生预览遮挡窗口和输入的问题。

### 界面与性能

- 合并品牌与标题栏，启动区整合游戏状态、客户端选择和错误提示；游戏模式与默认客户端入口移至设置，本地谱面及谱库管理保留 Stable／lazer 切换。
- 设置与工具集合改为保留背景的弹窗，分类切换保留内容和滚动位置；统一弹窗与通知组件、状态色、无障碍语义以及明暗主题。数据中心保留公共页头，切换子页仅显示局部骨架。
- 收藏与相似谱面首页使用限量、去重的本地封面拼贴，支持减少动态效果；候选舞台使用当前谱面高清背景，修复浅色主题搜索框、面板与图表配色。
- 交互查询、后台计算和阻塞 I/O 使用独立工作池，限制线程预算与队列；合并文件监听和并发封面／数据集加载，增加搜索去抖，修复排队查重取消失效及旧数据集覆盖缓存。
- 本地搜索与深分页复用索引，仅构造当前页；收藏按摘要和修订号分页，首次使用才加载。减少页面重挂载、播放器进度和未变化索引引起的刷新，隐藏窗口暂停轮询与重绘。
- 设置和缓存 I/O 移出主线程，日志采用有界队列、批量写入和正常退出排空；修复启动索引恢复时序与重复扫描。开发说明集中于[架构与开发](./架构与开发.md)。

## v0.4.3

- 新增 Skin Workshop：可打开 Stable Skin 或 `.osk` 包，暂存并融合部件、资源和 `skin.ini` 配置；支持覆盖前校验或另存为新 Skin。

- 更新 pp 计算依赖至 `Apeuriox/rosu-pp@pp-rework-202607`，同步最新 pp rework 算法快照。
- 改善 Linux 下客户端启动、文件定位、音频解码和 Wayland 渲染提示，并修复 Danser、tosu、游戏会话及本地资源扫描中的多项问题。
