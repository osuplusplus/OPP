# 比赛图池 URI 联动

OPP 支持通过 `opp://` 打开比赛图池。当前提供 Rino osu!standard 图池适配，官网无需传入曲包元数据或下载地址。

## 官网按钮

```html
<a href="opp://mappool/rino?season=s1&amp;category=qualification">
  在 OPP 中查看图池
</a>
```

URI 示例：`opp://mappool/rino?season=s1&category=qualification`。

| 参数 | 支持值 |
| --- | --- |
| `season` | `s1`、`s2` |
| `category` | `qualification`、`ro16`、`quarterfinals`、`semifinals`、`finals`、`grandfinals` |

参数均必填，不允许重复。其他入口、额外参数、用户名、端口和 fragment 不被接受。不能通过 URI 指定 API 地址、下载地址、保存路径或自动执行动作。

用户点击后，浏览器可能询问是否打开 OPP。OPP 恢复主窗口，在现有登录流程完成后显示图池弹窗。重复通知不会叠加弹窗，关闭后再次点击可以重新打开；尚未处理的多个不同图池链接保留最近一个。

## 用户操作

- 弹窗按图位显示谱面、选图人、评论、比赛定制及原创标记。点击谱面标题进入现有在线谱面详情。
- **同步到收藏**：重新获取官网图池，每赛季每阶段创建或更新一个 OPP 收藏夹。再次同步严格替换内容，移除旧图及手动添加的条目；保留收藏夹 ID、用户修改的名称和创建时间。不自动写回 Stable／lazer。
- 官网请求失败、数据校验失败或空图池时不创建／清空收藏夹。单张谱面资料查询失败仍可按 BID 收藏，再次同步可补全资料。
- **下载图池**：只在点击后开始，按曲包合并并校验包含指定难度。沿用已有下载源、目录、视频与下载后打开设置；没有目录时让用户选择。不可下载的条目列出并跳过，不影响其他条目。
- 下载复用 OPP 的当前下载会话，关闭弹窗不会取消下载。已有任务运行时不能从弹窗启动另一批，可查看进度或取消当前任务。
- 通过刷新重试数据读取。未发布阶段显示空状态。

## 协议注册与便携版

Windows、Linux 发布构建每次正常启动都会注册 `opp` 协议，注册目标为当前程序路径。便携版首次使用需要先运行一次；移动或重命名后也需要先从新位置运行一次。注册失败会记录日志但不会阻止启动。

Windows 使用当前用户的协议注册，无需管理员权限。Linux 使用当前用户的 desktop handler，需要 `xdg-mime` 和 `update-desktop-database`。不支持尚未下载／从未运行 OPP 时直接通过链接安装应用。

开发构建不自动覆盖正式版协议注册；可直接传入 URI 测试启动参数。便携更新助手不会注册协议。

## 数据与内部接口

Rust 固定请求 `https://rino.ink/api/map-selections`，参数为 `season`、`category`、`approved=true`、`padding=true`。请求超时、非成功状态、响应过大、重复图位、错误阶段或非法 BID 都返回错误，不将错误响应当成空图池。

条目只适配比赛元数据：BID、`selectedMods`、`modPosition`、选图人 ID／名称、评论、`isCustome`（比赛定制）、`isOrigin`（原创）。NM、HD、HR、DT、LZ、TB 等类型保持原值，不作为 osu! Mod 参数解释。谱面资料通过现有 osu! API 客户端／Nerinyan provider 补全；不使用比赛接口附带的星数、封面、时长等数据。

Tauri 命令：

- `get_tournament_pool({ reference })` → `TournamentPool`
- `sync_tournament_pool_collection({ reference })` → `{ folder_id, entry_count, pool }`
- `get_pending_tournament_link()` → `{ id, reference } | null`
- `acknowledge_tournament_link({ id })` → 确认消费对应唤起请求，旧请求不会清除新请求

`reference` 为 `{ provider: "rino", season, category }`；事件 `tournament-pool-open` 只发给主窗口，携带请求 ID 与 reference。公共 TypeScript 契约位于 `src/shared/types/osu.ts`，命令适配位于 `src/shared/lib/tauri.ts`。后续 Hub／Collection 重构可复用比赛功能的 Query API。

比赛下载复用 `download_online_beatmapsets`，条目传入所有选中难度的 `expected_beatmap_ids` 和 `allow_extra_difficulties: true`，校验曲包包含这些难度。省略新增字段时继续使用原有精确匹配，兼容普通在线下载调用。

比赛数据与普通收藏条目分离。收藏夹使用 `tournament:rino:<season>:<category>` 来源标识关联，收藏只写入指定难度，不扩展成整个曲包的所有难度。

## 发布验收

分别在 Windows 和 Linux 实机检查：首次注册、浏览器冷启动唤起、运行中唤起、托盘隐藏、迷你播放器恢复、登录后恢复请求、重复点击、移动程序后重新注册，以及刷新／收藏替换／取消下载。

自动化测试覆盖 URI 校验、请求去重、接口适配、元数据部分失败、收藏替换与持久化、弹窗操作及下载曲包合并；它们不能代替各平台的浏览器与桌面协议处理实测。
