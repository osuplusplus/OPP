# 收藏夹浏览与个人记录

收藏页分为首页文件夹网格和文件夹内谱面列表。搜索始终覆盖全部收藏，包括曲名、ID、图位、选图人、比赛评论、个人标签、笔记和手动成绩备注；多个词可以跨字段命中。搜索由 Rust 在完整数据上执行，结果按页返回。

点击谱面进入本地谱面页面，显式选择客户端、模式、谱面集及难度；返回恢复收藏页 URL、分页和滚动位置。缺失谱面保留个人记录入口，可从更多操作补齐。背景仅读取本地缩略图，每批最多 24 张；关闭动态效果或系统要求减少动画时保持静态。

收藏页与相似谱面首页共用原色、轻模糊的拼贴组件，使用中性遮罩控制亮度，浅色模式单独适配文字与面板。相似谱面的图片引用在启动索引就绪后从 Stable／lazer 全部本地谱面随机选取，按背景去重并缓存最多 24 项；只在显示页面时加载缩略图，候选切换不会重新抽样；相似谱面候选舞台改用当前候选的高清背景，隐藏首页拼贴。索引尚为空时允许后续扫描补充首次样本，非空样本在此次启动内保持固定。

## 存储与同步

- `collection-notes/<收藏夹 ID 的 SHA-256>.json` 保存版本为 1 的个人记录；图池快照与成员一起保存在收藏分片中，兼容读取旧 `collection-pools/` 独立快照。文件名不直接使用用户输入，同步比赛不会重写个人记录文件。
- 记录优先通过难度 BID 识别，无 BID 时使用 MD5，再回退到条目 ID。获取 BID／MD5 后写入时迁移旧身份。不同收藏夹互不影响。
- 保存使用修订号检测冲突、临时文件及原子替换。损坏或未知版本文件报错并保留，不当成空文件覆盖；前端失败草稿保留在当前应用会话中。
- 笔记修改不设置游戏收藏的 `pending_write`。游戏来源只读不影响 OPP 个人记录。比赛同步只更新成员及来源快照，移出条目的记录保留，重新加入可恢复；删除收藏夹同时删除其记录文件。
- 比赛快照与成员列表分离，允许同一个 BID 占多个图位。所有图位行共用该收藏夹内同一份个人记录。旧比赛收藏没有快照时仍提供显式同步入口。

URI 图池默认仅保存在 OPP，下载与导入 Stable 分别操作；在线参数随快照保存，旧快照可单独补全资料。完整流程见 [OPP URI 标准](./OPP-URI标准.md)。

## 本地成绩

Stable 读取安装目录的 `scores.db`，lazer 复制 `client.realm` 后读取 `ScoreInfo` 映射的 `Score` 表、关联用户和模式。游戏数据库从不写入。数据库大小／修改时间变化后重新解析；读取前后指纹不同则保留旧结果，提示稍后刷新。成绩缓存按谱面内容哈希索引，避免每次列出收藏时扫描全部成绩。

Stable 以 MD5 匹配，lazer 以谱面内容 SHA-256 匹配，结合本地资源索引关联收藏难度；明确的旧哈希不回退到同 BID 的新文件。成绩按模式及玩家筛选，未确定玩家时不自动显示其他玩家的历史。保留客户端与计分体系，不跨体系选取所谓最高分；默认展示最近记录。

手动成绩与代表成绩快照保存在对应收藏夹。自动成绩只读，代表成绩的原记录不可用时仍保留快照。自动记录不是完整的在线成绩库，也不包含尚未落盘的游戏内游玩。

## 接口

- `query_collection_browser({ query })`：分页浏览或全收藏搜索，附带本地定位、比赛图位、个人记录和命中片段。
- `save_collection_record({ folderId, entryId, record })`：带修订号保存个人记录。
- `get_collection_record({ folderId, entryId })`：精确重读个人记录，用于保存冲突后的显式恢复。
- `get_collection_entry_scores({ folderId, entryId, player })`：读取该精确难度的本地历史，`player: null` 返回全部候选，界面单独筛选。
- `get_collection_artwork({ folderId, offset })`：读取去重后的背景资源引用，最多 24 项。
- `get_local_artwork_sample()`：读取当前启动会话的本地随机背景引用，最多 24 项，不解码原图。
- `refresh_local_scores({ force })`：检查两个客户端成绩库，返回玩家、默认玩家与各源错误状态。

现有收藏命令、Stable／lazer 同步和 OPPC2 分享格式继续兼容。个人记录不进入分享码。

## 验证

自动化测试使用合成成绩、Realm 字段和收藏数据，覆盖片段搜索、10,000 条收藏的分页、同图多图位、笔记重启恢复、修订冲突、读取失败、玩家／哈希匹配和只读文件行为。浏览器验证使用测试曲包及占位背景，不访问用户游戏数据。

这些检查不能替代 Windows 与 Linux 下真实游戏数据库和桌面窗口的实机验收，尤其是不同 lazer Realm 版本和游戏正在写入时的行为。
