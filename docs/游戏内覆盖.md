# 游戏内覆盖（Overlay）

OPP 的游戏内覆盖层采用 **Steam 式交互**：平时完全隐藏、不遮挡游戏画面，按全局热键
（默认 `Ctrl+Shift+O`）随时唤出可交互的 Direct 侧栏，再按热键或 `Esc` 收起。显示通道：

- **Direct 面板**（热键唤出）：osu!direct 替代——官网同款封面卡片（状态徽标、标题、
  mapper、播放/收藏数、彩色难度星数条）、本地已有标记、一键下载导入；附多人聊天页。
- **HUD 状态卡**（可选常驻，默认关闭）：点击穿透的角落小卡，展示菜单状态、当前谱面、
  下载进度、MP 补缺状态、未读聊天与 IRC 异常。
- **tosu 游戏内渲染**（全屏方案）：把 OPP HUD 装入 tosu 内置的 ingame overlay
  （asdf-overlay，D3D/OpenGL 钩子直接绘制进游戏画面），**独占全屏下也可见**，由 tosu 的
  热键（默认 `Ctrl+Shift+Space`）显隐。

功能：

- **谱面搜索下载**：游戏内搜索（需 OPP 登录 osu! 账户）、本地已有标记、一键下载导入。
- **多人房间自动补缺**：通过 osu! IRC 监听房主换图，本地缺失自动下载并导入（详见下文）。
- **MP 聊天与翻译**：`#mp_` 频道全员消息 + 自动翻译，详见下文。

## 前置条件

| 条件 | 说明 |
| --- | --- |
| tosu | 两条通道的数据源。可在设置中"随游戏自动启动"（OPP 托管启动时自动关闭 tosu 的浏览器弹窗） |
| osu! IRC 令牌 | 多人补缺必需。在 [osu! 账户页](https://osu.ppy.sh/home/account/edit#irc) 生成，保存到系统凭据管理器 |
| OPP 登录 osu! 账户 | Direct 面板搜索与补缺元数据解析（与主窗口在线谱面一致） |
| 谱面下载目录 | 沿用「设置 > 在线谱面」的默认下载位置与镜像 |
| tosu 较新版本 | 仅游戏内渲染通道需要（内置 ingame overlay；首次启用可能联网下载组件） |

## 多人补缺工作方式（osu! IRC 通路）

tosu **不读取**多人大厅的谱面信息（只反映本地选图/游玩中的谱面），因此 MP 检测走
osu! Bancho IRC——与裁判机器人（bancho.js 等）相同的通路：

1. 游戏运行时 OPP 连接 `irc.ppy.sh:6667`（明文 PASS 认证，osu! 官方现状）。
2. 进入多人房间后，通过 WHOIS 频道发现 + JOIN 镜像自动加入对应 `#mp_<房间ID>` 频道。
3. 房主换图时 BanchoBot 播报 `Beatmap changed to: … (https://osu.ppy.sh/b/<ID>)`，
   即使本地没有该谱面也能实时收到。
4. OPP 按 beatmap id 解析元数据（官方 API）→ 本地 presence 检查（unknown 按缺失处理）→
   缺失时经默认镜像下载（允许镜像包自带额外难度）→ 自动交给 osu! 导入（运行中同样有效）。
5. 补缺编排**完全在后端**，与覆盖层窗口/主窗口状态无关；单飞锁被主窗口手动下载占用时
   自动等待重试。

注意：osu! IRC 为明文认证（官方未提供 TLS），令牌请妥善保管；介意明文传输请勿启用。

## 聊天与翻译（MP 频道）

复用上面同一条 IRC 连接：`#mp_` 频道里**所有玩家**的聊天消息（不只 BanchoBot）
都会进入 OPP 的聊天缓冲（后端环形缓冲，保留最近 300 条，与窗口生命周期无关），
Direct 面板的"聊天"标签页与 tosu 游戏内渲染页的聊天条共享同一份数据。

- **收**：消息原文先显示，后端自动翻译（若启用）完成后译文以 `↳` 附在原文下方；
  已是目标语言、纯表情/数字/链接的消息自动跳过。HUD 收起期间的新消息显示未读徽标。
- **发**：聊天页输入框输入中文 → 回车/按钮翻译 → 结果条展示译文并提供**复制**按钮
  （同时可复制原文）→ 切回游戏在聊天框 `Ctrl+V` 粘贴发送。OPP 不通过 IRC 发送消息，
  因此没有账号风险；代价是 IRC 无自发回显，游戏里发出的自己消息不会出现在 OPP 聊天里。

**连接状态可见化**：聊天页顶部与 HUD 会显示 IRC 的连接状态——凭据未配置、认证失败
（令牌/用户名错误，服务器会主动断开且不再重连）、连接中/未连接都有明确提示与指引。
稳定收不到聊天时先看这里的横幅再排查网络。

翻译服务（设置 > 游戏覆盖 > 聊天翻译，凭据仅存系统密钥环）：

| 服务 | 免费额度 | 说明 |
| --- | --- | --- |
| Google 免费端点（默认） | 无限（非官方） | 零配置；国内需代理（自动发现本机 Clash 等代理） |
| 腾讯云机器翻译 | 500 万字符/月 | 国内直连；腾讯云实名账号 + SecretId/SecretKey，后付费默认关闭 |
| 百度翻译 | 标准版 5 万字符/月（个人认证 100 万） | 国内直连；开放平台 APP ID + 密钥 |
| LLM（OpenAI 兼容） | GLM-4-Flash 免费 | 内置 osu! 玩家黑话对照（EZ/727/farm/choke/下饭/整活等），俚语/梗质量最好；兼容 DeepSeek/OpenAI/Ollama |

隐私提示：聊天内容会发送到所配置的翻译服务处理。

## tosu 游戏内渲染的安装方式

设置 > 游戏覆盖 > 启用"tosu 游戏内渲染"时，OPP 会：

1. 写入 `<tosu 目录>/static/opp-hud/`（自包含 HUD 页 + gosumemory 兼容的 metadata.txt）。
2. 在 `<tosu 目录>/settings/__ingame__.values.json` 的当前 ingame profile 中合并 OPP 条目
   （保留用户其他覆盖配置；卸载时移除）。
3. 在 `<tosu 目录>/tosu.env` 写入 `ENABLE_INGAME_OVERLAY=true`。

**需要重启 tosu 生效**。HUD 页通过 OPP 本地状态服务（`http://127.0.0.1:24099/api/status`，
仅绑定回环地址）轮询 MP 补缺/下载进度/tosu 快照。tosu 升级后如失效，在设置页点"重新安装"。

## 行为细节

- Steam 式交互：覆盖层默认隐藏，热键唤出 Direct 面板，再按热键或面板内 `Esc` 收起；
  从 HUD 常驻态唤出时收起回到 HUD，从隐藏态唤出时收起回到隐藏。
- 窗口隐藏不销毁（关闭请求转为隐藏）；热键与窗口模式切换不受影响。
- 面板收起时键盘焦点自动归还给打开前的窗口（Windows），避免吞掉游戏按键。
- 下载进度事件广播到所有窗口：主窗口发起的下载同样显示在 HUD 上。
- tosu WebSocket 断线后自动指数退避重连（2s 起、30s 封顶）；IRC 认证失败不重连
  （改凭据后自动重连），其余断线按退避重连。
- 设置项：启用开关、随游戏自动启动 tosu、常驻 HUD 状态卡（默认关）、游戏退出自动
  隐藏、角落、穿透、热键（可录制）、MP 自动下载、游戏内渲染、IRC 凭据（用户名 +
  令牌）、聊天翻译（服务/开关/目标语言/凭据）。

## 技术实现

```text
src-tauri/src/features/overlay/
├── service.rs        # 置顶窗口生命周期、热键、游戏状态钩子、焦点归还
├── irc.rs            # osu! IRC 客户端 + MP 补缺编排 + 聊天缓冲（后端常驻）+ OverlayRuntime
├── ingame.rs         # tosu ingame 安装器 + 本地状态 HTTP 服务（axum, :24099）
├── ingame_hud.html   # 部署进 tosu static 的自包含 HUD 页（含聊天条）
└── commands.rs       # 命令层
src-tauri/src/features/translation/   # 翻译：4 提供方适配器 + LRU 缓存 + 必要性判定
src/features/overlay/ # 前端：HUD 卡片、Direct 面板（谱面/聊天标签页）、状态订阅（纯展示）
```

- 相关命令：`overlay_get_state` / `overlay_set_mode`（`hidden` | `hud` | `panel`）/
  `overlay_close_panel` / `overlay_set_visible` / `overlay_test_hotkey` /
  `overlay_get_mp_status` / `overlay_set_irc_credentials` / `overlay_install_ingame` /
  `overlay_uninstall_ingame` / `overlay_get_chat` / `overlay_copy_text` /
  `translate_texts` / `translation_set_credential` / `translation_test`
- 相关事件：`overlay-mode-changed`、`overlay-mp-activity`、`overlay-chat-message`、
  `overlay-chat-updated`、`tosu-live-data`、`beatmap-download-progress`
- IRC 消息解析（玩家聊天/BanchoBot 播报/WHOIS 319/JOIN 镜像/控制码剥离）、各翻译
  适配器（百度 MD5 签名官方向量、腾讯 TC3 签名、Google 端点响应、LLM 编号行）与
  翻译必要性启发式均有单元测试。
- 平台支持：Windows 已实现；Linux 需要 X11（Wayland 不支持透明置顶窗），IRC 与
  ingame 通道不依赖平台窗口特性，待实测。
